01 · The idea, simply

Give your AI a map instead of a pile of files

When you use Claude Code on a big project, the AI has to "read" everything to understand how it all connects. Graphify does that work once and leaves the map ready.

Free & open source

With the map already built, your AI doesn't need to re-read everything every time. Result: faster, more accurate answers, and way less spend.

03 · Is it hard to install?

No. Just a couple steps

You don't need to be an expert: install it with one command, then inside Claude Code type /graphify . so it maps your current project. That's it.
